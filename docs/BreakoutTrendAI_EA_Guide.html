Overview

BreakoutTrendAI is a fully autonomous, self-learning Expert Advisor for MetaTrader 5. It combines a classical 20-bar range breakout strategy with an online Multi-Layer Perceptron (MLP) that improves after every closed trade. Designed specifically for prop firm challenges — it has built-in daily/weekly loss limits, session filters, and a SafeGuard circuit breaker.

Key design principle: Every filter must pass before a trade opens. If any step fails, the dashboard shows exactly why (OUT OF SESSION / NO TREND / NO BREAKOUT / SCORE LOW / etc.)

Trend Filter (Step 4)

DirectionCondition
BUY signalM15 close > H1 EMA50 AND RSI(14) > 45
SELL signalM15 close < H1 EMA50 AND RSI(14) < 55

Range Breakout (Step 5)

Range = highest high / lowest low of bars 2 to 21 (bar 1 excluded so bar 1's close can actually break out). Range must be 0.5×ATR – 5.0×ATR wide (ATR-based filter replaces fixed pip filter).

Learning Cycle

When a trade closes:
1. Profit (incl. swap + commission) is converted to a label using: label = sigmoid(profit% × 20)
2. Backpropagation updates weights using SGD + Momentum (lr=0.001, momentum=0.90)
3. Model saved to btai_<symbol>.dat every 5 trades

Bootstrap Mode

First 10 trades per pair: threshold lowered to 0.40 (from 0.54–0.60) so the AI collects real trade outcomes to learn from. After 10 trades, the full threshold applies.

SafeGuard EA — Account Circuit Breaker

A separate EA (MQL5\Experts\SafeGuard_EA.mq5) that runs on one chart only and monitors the entire account. When a trigger fires, it closes ALL open positions and locks BreakoutTrendAI via a GlobalVariable for a set period.

TriggerDefaultAction
Dollar loss limit$500 (range: $100–$1,200)Close all + lock for Pause Hours
Drawdown %3.0% of accountClose all + lock for Pause Hours
Consecutive losses3 in a rowClose all + lock for Pause Hours
Pause duration4 hoursAuto-unlocks after timer expires
Daily reset00:00 UTCLoss counters reset, lock cleared
Communication method: SafeGuard writes a GlobalVariable SAFEGUARD_<AccountLogin> = expiry timestamp. BreakoutTrendAI reads this on every bar — if current time < expiry, all entries are blocked.

Step 2 — Compile in MetaEditor

1. Open MetaEditor (press F4 in MT5) 2. Open BreakoutTrendAI_Single.mq5 3. Press F7 to compile → must show 0 errors 4. Repeat for SafeGuard_EA.mq5

Step 3 — Attach to Charts

Open 6 × M15 charts: EURUSD · GBPUSD · XAUUSD · USDJPY · GBPJPY · AUDUSD For each chart: → Drag BreakoutTrendAI_Single from Navigator → Expert Advisors → Properties → Load (bottom left) → select the matching .set file → Click OK Open 1 extra chart (any symbol): → Attach SafeGuard_EA (no preset needed) → Set Inp_MaxDollarLoss to your risk tolerance ($100–$1,200)

Step 4 — Verify

Dashboard should show: ● RUNNING · Session name · Train Steps: 0 (BOOTSTRAP)
After the first closed trade on each pair, check MT5 Files folder — you should see 6 separate .dat files appearing (one per pair).
